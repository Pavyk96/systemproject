Техническое задание
Проект: «Система управления проектами»
1. Описание проекта
Приложение предназначено для управления проектами и задачами внутри них. Система позволяет создавать проекты, добавлять участников и назначать задачи.
2. Сущности
Пользователь
* id
* логин
* пароль
* роль
Проект
* id
* название
* описание
Задача
* id
* название
* описание
* статус
* проект
* исполнитель
Роль
* ADMIN
* USER
3. Функциональные требования
Администратор может:
* просматривать всех пользователей системы
* создавать проекты
* редактировать проекты
* удалять проекты
* добавлять пользователей в проект
* удалять пользователей из проекта
* просматривать все задачи
* создавать задачи
* редактировать задачи
* назначать задачи пользователям
* изменять статус любой задачи
Пользователь может:
* просматривать проекты, в которых он участвует
* просматривать назначенные ему задачи
* изменять статус только своих задач
4. Авторизация и аутентификация
* пользователь регистрируется в системе
* вход осуществляется по логину и паролю
* доступ к функционалу ограничен в зависимости от роли пользователя
5. Правила доступа
* только ADMIN может управлять проектами и пользователями
* USER не может изменять проекты
* USER может работать только со своими задачами
6. Статусы задач
* NEW
* IN_PROGRESS
* DONE
7. База данных
Приложение использует реляционную базу данных. В базе хранятся:
* пользователи
* роли
* проекты
* задачи
8. Технические требования
* приложение реализовано на Spring Framework
* используется ORM Hibernate
* пароли хранятся в зашифрованном виде
* приложение имеет слоистую архитектуру (представление, бизнес-логика, данные)
9. GUI интерфейс
В приложении должен присутствовать GUI интерфейс, соответствующий реализуемой функциональности.
